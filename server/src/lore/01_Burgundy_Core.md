# 《金羊毛之地》世界觀設定

## 一、核心概念

這是一個以**15世紀勃艮第公國**為歷史原型、揉合奇幻元素的世界。沒有精靈或矮人式的種族奇幻,而是「**信仰時代的隱性魔法**」——魔法存在,但被宗教、行會、貴族體制壓抑、包裝、壟斷,如同煉金術與占星術曾真實存在於歷史中一樣。

關鍵字:**騎士精神、行會經濟、宮廷陰謀、教會與異端、聖物與秘術**。

---

## 二、地理與政治格局

### 「低地公國」(藍登地, Landen)
原型對應勃艮第公國本身——一個由**眾多原本獨立的伯爵領、公爵領、自治市**透過聯姻、戰爭、繼承拼湊起來的「拼布國家」,沒有單一首都,權力分散在:

- **第戎(Dijon)式首府** —— 公爵的祖傳領地,宮廷禮儀、騎士團、藝術贊助的中心
- **布魯日式商業城** —— 自治程度極高,行會掌握實權,公爵需要「借錢」而非「下令」
- **根特式叛逆城** —— 富裕到敢於對公爵舉起武器的紡織業重鎮,城市自治傳統深厚

這種結構天生適合冒險:公爵的命令在這座城市是法律,在隔壁城市卻只是「建議」。

### 周邊強權(可依你的需要對應現實或完全虛構)
- **南方王國** —— 對應法蘭西,法理上是低地公國貴族的「宗主」,但實際上管不動,長期覬覦低地公國的財富
- **東方帝國** —— 對應神聖羅馬帝國,鬆散、官僚、宗教法庭的源頭
- **海上同盟** —— 對應漢薩同盟,純商業性的城市聯盟,跟低地公國的行會互為對手又互利

## 三、隱性魔法系統:「大奧秘」(Magnum Arcanum)

魔法不被稱為魔法,而是被分散包裝進現實制度中:

| 表面身份 | 實際性質 |
|---|---|
| **占星師/御醫** | 真正能讀解命運線索、調配具魔效的藥劑 |
| **金匠行會大師** | 部分高階金匠掌握「賦魔」工藝,打造的飾品、武器真有奇效,但行會嚴格保密配方 |
| **修道院抄寫士** | 抄錄典籍時,少數人能「喚醒」書中封存的古老咒文(類似活字版前的手抄秘術) |
| **異端/女巫審判對象** | 真正的自由施法者,多是被體制排斥、藏身鄉野的存在,危險但強大 |
| **聖物與聖髑** | 教會收藏的「聖人遺物」中,確實有一部分擁有真實神力,教會自己也未必完全清楚哪些是真的 |

**設計核心**:魔法力量永遠跟「身份地位」綁定。一個農夫不會說自己會魔法,他只會說「我外婆教我這個草藥配方,別說出去」。這讓魔法天然帶有秘密、禁忌、社會階級的張力,非常適合LM操作的陰謀/調查/宮廷類冒險。

## 四、社會結構與衝突引擎

1. **公爵宮廷 vs. 商業城市**
 公爵需要城市的稅金與借款打仗,城市需要公爵的軍隊保護貿易路線——互相依賴又互相提防,是天然的政治冒險素材。

2. **騎士團與騎士精神的衰落**
 設立一個對應「金羊毛騎士團」的虛構騎士團,表面上是榮譽至高的存在,實則內部充滿派系鬥爭——舊貴族騎士(重視血統與傳統)與新興「靠戰功封爵」的騎士互相看不起。

3. **教會的雙重面孔**
 一邊是壓制異端、收取什一稅的龐大官僚機構,一邊內部也有真正虔誠、甚至擁有聖術的修士——玩家永遠無法簡單判斷某個神職人員是貪腐還是神聖。

4. **行會的隱密階層**
 表面上是「金匠行會」「織布行會」「醫師行會」,實際上每個行會內部都有一層只有大師才知道的「奧秘核心」,新人要花十年才可能被允許窺見一角。

5. **黑死病的陰影**(可選)
 如果你的遊戲需要更黑暗的調性,可以保留歷史上瘟疫剛過、人口銳減、勞動力短缺造成的社會劇變這個背景,作為長期的不安定因素。
