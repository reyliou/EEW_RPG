# 世界觀分層架構:讓「常規奇幻RPG手感」與「深度設定」並存

## 問題診斷

你原本的設定文件本質上是「設定資料庫」,適合你自己當參考,但**不適合直接餵給AI當開場敘事的唯一依據**。AI讀了那份文件後,會傾向把所有專有名詞當「玩家應該已經知道」的常識直接拋出來,因為文件裡寫的時候就是這樣的語氣。

解法不是砍掉深度,而是**多寫一層「翻譯介面」**,專門規範「AI第一次提到某個東西時該怎麼說」。

---

## 一、命名雙軌制

每個重要名詞都有兩個版本:

| 深度層原名 | 主線層稱呼(玩家初次接觸時用這個) |
|---|---|
| 藍石城 / 藍金廳 | 「公爵的都城」 |
| 織金港 / 織金會 | 「商會掌權的港口城」 |
| 灰塔城 / 灰塔議事廳 | 「自治的紡織之城」 |
| 白岩鎮 / 聖髑座堂 | 「教會的朝聖之城」 |
| 金羊毛廳 / 金羊毛騎士團 | 「公爵的騎士團」 |
| 霧澤 | 「邊境的霧地」 |
| 鯨脊群島 / 北灣行棟 | 「外海的商人群島」 |

**規則**:專有名詞只在「玩家已經去過那個地方、或NPC很自然地用簡稱」之後才開始被AI正式使用。第一次提到永遠用左欄「功能性稱呼+一句話描述」帶出,例如:

> 「你抵達了公爵的都城——人們叫它**藍石城**,因為城堡建在一片青灰色的岩丘上。」

這樣專有名詞是**裝飾在後面補充的**,不是必須先知道的門檻。

## 二、給AI(LM)的具體指令範本

你可以把這段直接放進系統提示詞或世界觀文件最前面:

```
【敘事規則:專有名詞揭露原則】
1. 任何專有名詞(地名、組織名、頭銜)第一次出現時,必須先用「功能性說明」帶出,
   再附上正式名稱。例如:不要直接說「你來到了灰塔城」,
   而要說「你來到了一座自治的紡織城市,當地人稱它灰塔城」。
2. 不要假設玩家知道任何派系之間的恩怨。如果劇情需要派系背景知識,
   要透過NPC對話「順便提一句」帶出,而不是用旁白整段解釋世界觀。
3. 深度設定(各勢力秘密、NPC隱藏動機)屬於「主動挖掘才會揭露」的內容,
   不應在沒有玩家行動觸發的情況下主動劇透。
4. 優先使用常規奇幻RPG的熟悉原型(公爵、騎士、商會、教會、自由城市)
   作為敘事骨架,專有名詞是這些原型的「風味調味」,不是必修內容。
```

## 三、「常規奇幻RPG手感」具體怎麼做到

常規奇幻RPG(無論是DnD式或JRPG式)讓人覺得好懂,核心是這幾個套路,你現有設定完全可以套進去,只是要把「原型」擺在前面:

1. **玩家起點永遠是熟悉的小地方**,不是直接丟進複雜的宮廷政治。例如開場可以是「邊境小鎮」或「某座城市的貧民區」,讓玩家先建立對「這個世界長什麼樣」的直覺,再慢慢被捲入大局。

2. **第一個遇到的NPC不該是核心關鍵NPC**。先讓玩家遇到小角色(旅店老闆、傭兵、地方官),這些小角色可以「轉述」對大勢力的印象(「聽說公爵又要加稅了」),而不是讓玩家一開局就跟公爵本人打交道。

3. **派系不要一次全部登場**。常規RPG的手感是「先知道一兩個勢力,玩到後面才發現背後還有更多盤算」。建議你的7大勢力分批揭露,例如前期只需要玩家知道「公爵」跟「商會」這兩個最表層的對立,其他5個當「DLC」逐步解鎖。

4. **專有名詞先當形容詞用,再變成名字**。例如「金羊毛騎士團」第一次出現時可以說成「公爵手下最精銳的騎士」,等玩家在故事裡聽到第三、四次,AI才開始直接用「金羊毛騎士團」這個稱呼,這時玩家已經有上下文,不會覺得突然冒出一個生詞。

## 四、建議的文件結構(讓AI閱讀時自然分層)

建議把你的世界觀資料拆成兩份檔案餵給LM:

- **`世界觀_主線層.md`**——只包含「公爵/商會/教會/騎士團/自治城市」這種原型層級的描述,加上上面的「揭露規則」,當作AI的**預設行為基準**。
- **`世界觀_深度層.md`**(你現有的勢力關係+NPC秘密+地名全名)——標註「僅在玩家深入調查、或劇情自然推進到此處時才取用」,當作**選用知識庫**,而不是預設要套用的東西。

這樣AI在一般跑團時,行為會像個正常的奇幻RPG主持人;只有當玩家主動往深處挖,它才會「打開DLC」,把你精心設計的勃艮第式政治陰謀端出來。
